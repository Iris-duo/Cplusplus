# 位操作符的几道例题讲解

## 1.位操作符知识点回顾

位操作符分为：按位与(&)，按位或(|)，按位异或(^),按位取反(~)

首先表明他们的操作数都是整数，其次在计算机中是使用的它们的反码二进制表现形式进行计算。那么我们先来回顾一下原码、反码、补码的相关内容

### 1.1原码、反码与补码

整数的二进制表现形式有三种：原码、反码与补码

表现形式为：符号位(1/0)+数值位

符号位：1：”负“ 0:"正"

正数的原码、反码与补码都相同

负数：

- ​	原码：符号位(1)  + 数值位

- ​	补码：符号位不变，数值位按位取反

- ​	反码：反码+1

-    取反的条件是符号位不变

  ![](D:\Bit_operation\Images\整数的三种表示形式.png)

  ```C
  #define _CRT_SECURE_NO_WARNINGS 1
  #include<stdio.h>
  
  int main()
  {
  	int a = 5;
  	//a是正数原码、反码与补码都相同
  	//00000000 00000000 00000000 00000101
  
  	int b = -1;
  	//b是负数原码、反码与补码不同
  	//原码：10000000 00000000 00000000 00000001
  	//反码：11111111 11111111 11111111 11111110
  	//补码：11111111 11111111 11111111 11111111
  	return 0;
  }
  ```

  ### 1.2 位操作符计算规则

  ```c
  	int a = 3;
  	//a:00000000 00000000 00000000 00000011
  	int b = -5;
  	//原码：10000000 00000000 00000000 00000101
  	//反码：11111111 11111111 11111111 11111010
  	//补码：11111111 11111111 11111111 11111011
  ```

  #### 1.2.1 按位与(&)

  - 计算规则：有0则为0，全1才是1

    ```c
    int a = 3;
    int b = -5;
    int c = a & b;
    printf("a & b = %d\n",c);
    
    //通过反码进行按位与(&)计算
    //a: 00000000 00000000 00000000 00000011
    //b：11111111 11111111 11111111 11111011
    //c: 00000000 00000000 00000000 00000011
    //现在C的符号位为0说明是正数，可得c == 3
    ```

    

  #### 1.2.2 按位或(|)

  - 计算规则：有1则为1，全0才是0

  ```c
  int a = 3;
  int b = -5;
  int d = a | b;
  printf("a | b = %d\n",d);
  //通过反码进行按位或(|)计算
  //a: 00000000 00000000 00000000 00000011
  //b：11111111 11111111 11111111 11111011
  //d: 11111111 11111111 11111111 11111011
  //现在d与b的反码相同，那么可得d == b == -5
  ```

  #### 1.2.3 按位异或(^)

  - 计算规则：相同为0，相异为1

    ```c
    int a = 3;
    int b = -5;
    int e = a ^ b;
    printf("a ^ b = %d\n",e);
    //通过反码进行按位或(|)计算
    //a: 00000000 00000000 00000000 00000011
    //b：11111111 11111111 11111111 11111011
    //e: 11111111 11111111 11111111 11111000
    //对e取反+1得 10000000 00000000 00000000 00001000 即e == -8
    ```

    #### 1.2.4 按位取反

    - 计算规则：1变为0，0变为1

      ```c
      int f = ~0;
      printf("~0 = %d\n",f);
      //0:  00000000 00000000 00000000 00000000
      //~0: 11111111 11111111 11111111 11111111
      //在开头举例中我们知道-1的反码二进制表现形式为全1，所以 f == -1
      ```

      #### 1.2.5完整测试代码

      ```c
      int main()
      {
      	int a = 3;
      	//a:00000000 00000000 00000000 00000011
      	int b = -5;
      	//原码：10000000 00000000 00000000 00000101
      	//反码：11111111 11111111 11111111 11111010
      	//补码：11111111 11111111 11111111 11111011	
      	
      	int c = a & b;
      	int d = a | b;
      	int e = a ^ b;
      	int f = ~0;
      	
      	printf("a & b = %d\n", c);
      	printf("a | b = %d\n", d);
      	printf("a ^ b = %d\n", e);
      	printf("~0 = %d\n", f);	
      	return 0;
      }
      ```

  ## 2.例题讲解

  ### 2.1在不创建临时变量(第三个变量)的情况下，实现两个整数的交换

  一般看到**交换**，我们最先想到的就是使用第三个变量进行交换，但是这道题挺变态的居然不让我们使用第三个变量，那么我们应该怎么办呢？

  ##### 方法一：使用加减法

  ```c
  int a = 3;
  int b = 5;
  printf("交换前：a = %d, b = %d\n", a, b);
  
  //使用其中一个变量来表示两数之和
  a = a + b;
  //此时a表示的是两数之和所以我们可以通过a-b来得到b的值
  b = a - b;
  //此时a表示的是两数之和,b表示a的值所以我们可以通过a-b来得到a的值
  a = a - b;
  
  printf("交换后：a = %d, b = %d\n", a, b);
  ```
  
  ![](H:\Cplusplus\Cplusplus\Bit_operation\Images\综合版.png)

这种方法既没有使用第三个变量，也完成了两数的交换，但是在两个数都没有超过但是又无限逼近int类型可表示的数字范围时，两数相加就会出现溢出情况。，如图下图

![溢出](H:\Cplusplus\Cplusplus\Bit_operation\Images\溢出.png)

##### 方法二：异或法

```c
a = a ^ b; 
b = a ^ b;
a = a ^ b;
```

啊？这是什么，怎么有三个一样的语句呢？好现在我们来分析一下

首先按位异或的计算规则为：相同为0，相异为1

那么我们由此可得：

- ​	a ^ a = 0;
- ​	0 ^ a = a;

我们来分析这三行代码

```c
//a ^ a = 0, a ^ 0 = a
a = a ^ b;	
b = a ^ b;  //此时b = (a ^ b) ^ b = a ^ (b ^ b) = a ^ 0 = a
a = a ^ b;  //此时a = (a ^ b) ^ a = b ^ (a ^ a) = b ^ 0 = b 
```

那么这样会发生溢出这种情况吗，答案是完全不会的，因为按位异或运算不会产生进位，所以根本不会产生溢出的情况。

#### 2.2 求一个整数存储在内存中的二进制个数

##### 方法一：这个题我们很容易想到的是%2这个操作 那么我们来实现一下

```c
	int n = 0;
	printf("请输入要统计整数:>");
	while (scanf("%d", &n))
	{
        int count = 0;
		while (n)
		{
			if (n % 2 == 1)
			{
				count++;
			}
			n /= 2;
		}
		printf("在内存中的二进制表示中有 %d 个1\n", count);
		printf("\n");
	}
}
```

##### 方法二：一个整数的二进制表示方式有32位，那么我们可不可以一位一位的计算呢？

```c
分析
int a = 3;
//a：	00000000 00000000 00000000 00000011
//1：	00000000 00000000 00000000 00000001
//想要二者进行运算结果为1，就要进行按位与(&)操作[全为1才是1]
//结果：可得出最后一位为1
//那么如何计算下一位呢是对a进行操作还是1呢，这里我们既然要计算a中的每一位，那么我们可以对a进行右移操作，这样每次右移就可以去掉
//已经判断过的那一位，然后从左侧依次添加0

测试代码
int n = 0;
printf("请输入要统计整数:>");
while (scanf("%d", &n))
{
	int count = 0;
	int i = 0;
	for (i = 0; i < 32; i++)
	{
		if(((n >> i) & 1) == 1)
		{
			count++;
		}
	}
	printf("在内存中的二进制表示中有 %d 个1\n", count);
}
printf("\n");
```

##### 方法三：n &（n-1）算法

首先我们先简单了解一下这个算法（后续文章会出一篇关于这个算法的专题练习）

```
分析(只写二进制的最后四位) 
n = 15
n	1111		n	1110		n	1100		n	1000
n-1 1110		n-1	1101		n-1 1000		n-1 0111
res	1110		res 1100		res 1000		res 0000

```

由此可见：***n&(n-1)作用：将n的二进制表示中的最低位为1的改为0***

那么这道题我们还可以有另一个解法

```c
//方法三：n&(n-1)算法【将二进制中最低位的1变为0】
int n = 0;
printf("请输入要统计整数:>");
while (scanf("%d", &n))
{
	int count = 0;
	
	while (n)
	{
		n = n&(n - 1);
		count++;
	}
	
	printf("在内存中的二进制表示中有 %d 个1\n", count);
	printf("\n");
}
printf("\n");

```

#### 2.3 二进制某位置置0或1

##### 题目：将13二进制序列第5位修改为1，再改回0

```
分析：这里我们只写二进制的后八位
n = 13
n	00001101
13的二进制第五位是0，想要把第五位改为1，我们只需要将其与10000进行按位或操作，那么10000我们可以使用(1<<4)表示
那么修改后得到 00011101（1+0+4+8+16=29） 想要第五位再改回1，我们只需要将其与01111进行按位与操作，其中01111我们可以使用(~(1<<4))表示
```

```c
//题目：将13二进制序列第5位修改为1，再改回0
int n = 13;

n |= (1 << 4);
printf("%d\n", n);

n &= (~(1 << 4));
printf("%d\n", n);
```
