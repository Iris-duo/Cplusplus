# 函数的递归

## 1.什么是递归

搞懂递与归，大事化小，小事化了

通俗解释，函数递归就是函数自己调用自己，核心思想：大事化小，把一个大型复杂的问题拆成规模更小的同类子问题，其中递就是递推的意思，归就是回归的意思。

例子

```c
#define _CRT_SECURE_NO_WARNINGS 1
![死循环](H:\Cplusplus\Cplusplus\ArticleWirting\函数的递归\Images\死循环.png)
#include<stdio.h>

//史上最简单的C语言递归代码
int main()
{
	Printf("Hello");
	main();	//在main函数中调用main函数本身，形成递归
	return 0;
}
```

这个就是一个简单的递归程序，只不过这个代码只是为了演示递归的基本形式，不是为了解决问题，并且我们运行这个代码我们会发现这个代码会陷入死循环。

![](H:\Cplusplus\Cplusplus\ArticleWirting\函数的递归\Images\死循环.png)

由此我们可得递归并不是没有条件的，如果使用不当我们将会陷入死循环或者是栈溢出的情况

## 2.递归的限制条件

递归在书写的时候，有2个必要条件：
• 递归存在限制条件，当满⾜这个限制条件的时候，递归便不再继续。
• 每次递归调⽤之后越来越接近这个限制条件。
在下⾯的例⼦中，我们逐步体会这2个限制条件。

## 3.递归的举例

#### 例1：求n的阶乘

- [ ] 一个正整数的阶乘(factorial)是所有小于及等于该数的正整数的积，并且0的阶乘为1。自然数n的阶乘写作n！。

**题目：计算n的阶乘(不考虑溢出)，n的阶乘就是1~n的数字累积相乘。**

#### 分析与代码实现

我们知道n的阶乘公式是n!=n*(n-1)

```
举例：
	5！= 5*4*3*2*1
	4！= 4*3*2*1
所以：5！= 5*4！
```

这样的思路我们就可以把一个较大的问题，转换成一个与原问题相似但是规模又比较小的问题来解决。当n==0时，n的阶乘就是1，其余的都可以使用阶乘公式来计算

![](H:\Cplusplus\Cplusplus\ArticleWirting\函数的递归\Images\阶乘公式.png)



那么我们就可以写出函数Fact求n的阶乘，假设Fact(n)就是求n的阶乘，那么Fact(n-1)就是求n-1的阶乘，函数如下：

```c
int Fact(int n)
{
	if (n == 0)
		return 1;
	else
		return n * Fact(n - 1);
}
```

完整测试代码：

```c
#include<stdio.h>

int Fact(int n)
{
	if (n == 0)
		return 1;
	else
		return n * Fact(n - 1);
}

int main()
{
	int n = 0;
	printf("请输入要计算的值:> ");
	scanf("%d", &n);
	int ret = Fact(n);
	printf("%d 的阶乘是：%d\n", n, ret);
	return 0;
}
```

#### 例2：顺序打印一个整数的每一位

输入一个整数m，按照顺序打印整数的每一位。

比如：输入：1234   输出：1 2  3  4

​			输入：7698  输出：7  6  9  8

#### 分析与代码实现

看到这个题目我们首先想到的是怎么得到这个数的每一位呢？

如果n是一位数，那么每一位就是n自己

n超过一位数的话，就得拆分每一位

1234%10就能得到4，然后1234/10得到123，这就相当于去掉了4
然后继续对123%10，就得到了3，再除10去掉3，以此类推
不断的 %10 和 /10 操作，直到1234的每⼀位都得到
但是这⾥有个问题就是得到的数字顺序是倒着的

但是我们有了灵感，我们会发现其实一个数的最低位才是最容易得到的，通过%10就能得到，那么我们假设写一个Print函数打印n的每一位:

```
Print(n)
如果n=1234，那么表示Print(1234)

其中1234%10就可以得到4，那么我们就可以将这个函数拆分成两步：
Print(1234/10)	//打印123的每一位
printf(1234%10)	//打印4
完成上述两步，那就完成了1234的每一位打印

那么Print(123)又可以与上述步骤一样继续拆分，以此类推：
	Print(1234)
==>Print(123)						+printf(4)
==>Print(12)			+ printf(3)
==>Print(1) + printf(2)
==>printf(1)
```

那么直到打印的数字变为一位数时，就不需要拆分了，递归结束  

```c
void Print(int n)
{
	if (n > 9)
	{
		Print(n / 10);
	}
	printf("%d ", n%10);
}
```

完整测试代码：

```c
#include<stdio.h>

void Print(int n)
{
	if (n > 9)
	{
		Print(n / 10);
	}
	printf("%d ", n%10);
}

int main()
{
	int n = 0;
	printf("请输入要拆分的值:> ");	
	while(scanf("%d", &n))
	{
		Print(n);
		printf("\n");
		printf("请输入要拆分的值:> ");
	}
	return 0;
}
```
