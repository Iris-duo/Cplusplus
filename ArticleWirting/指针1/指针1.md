# 1. 内存和地址

### 1.1内存

在讲内存和地址之前我们先举一个生活中的案例

在大学生活中我们不可避免都住过宿舍，那么在一栋宿舍楼栋中如果没有楼层编号以及寝室编号，我们将A同学随便安排在一间宿舍里面，让B同学来寻找A同学，这是比较费时费力的。但是，如果我们根据楼层的基本信息对每一件寝室进行编号那么B同学就可以轻易找到A同学。

将这个例子对照到我们的计算机中，我们可以发现内存与地址其实也是这个道理。

我们知道计算机上CPU（中央处理器）在处理数据的时候，需要的数据是在内存中读取的，处理后的 数据也会放回内存中，那我们买电脑的时候，电脑上内存是8GB/16GB/32GB等，那这些内存空间如 何⾼效的管理呢？

其实也是把内存划分为⼀个个的内存单元，每个内存单元的⼤⼩取1个字节。其中，每个内存单元，相当于⼀个学⽣宿舍，⼀ 个字节空间⾥⾯能放8个⽐特位，就好⽐同学们住 的⼋⼈间，每个⼈是⼀个⽐特位。 每个内存单元也都有⼀个编号（这个编号就相当 于宿舍房间的⻔牌号），有了这个内存单元的编 号，CPU就可以快速找到⼀个内存空间。

  ### 1.2究竟应该如何理解编址呢？

  计算机中有许多的硬件单元要互相协同工作(相互之间能够进行数据传递)，但硬件与硬件之间是相互独立的，想要进行通信，就要用到“线”连接。而CPU与内存之间是有大量的数据交换的，所以二者之间也要用线连接起来。

  CPU访问内存中的某个字节空间，必须要知道在内存的什么位置，而因为内存中字节很多，所以需要对内存进行编址。计算机中的编址，并不是把每个字节的地址都记录下来，而是通过硬件完成。好比，钢琴上并没有写明“哆、瑞、咪、发、嗦、啦、西”这样的信息，而演奏家却能精准地知道每一个琴键的意思，这是因为制造商早已将这些在乐器行设计好了，并且演奏者们都知道，本质上是一种约定出来的共识。

  硬件编址也是如此，简单理解为，32位机器上有32根总线，每根总线有0/1两态(有无脉冲)，那么32根地址，就能表示2^32种含义，每一种含义表示一个地址。

  地址信息下达给内存，在内存上，就可以找到地址对应的数据，内存将数据通过数据线传输到相应位置。

### 2.2指针变量和解引用操作符(*)

```
int a = 0;
int* p = &a;	//p是一个变量(存放指针的变量)，是一块空间
```

- 指针		：地址
- 指针变量：存放地址的变量

**怎么理解int*呢？**

![](H:\Cplusplus\Cplusplus\ArticleWirting\指针1\Images\指针变量.png)

```c
int a = 100;
int* pa = &a;
*pa = 0;
return 0;
```

上⾯代码中就使⽤了解引⽤操作符， *pa  的意思就是通过pa中存放的地址，找到指向的空间， *pa其实就是a变量了；所以*pa=0，这个操作符是把a改成了0. 有同学肯定在想，这⾥如果⽬的就是把a改成0的话，写成 a = 0;  不就完了，为啥⾮要使⽤指针呢？ 其实这⾥是把a的修改交给了pa来操作，这样对a的修改，就多了⼀种的途径，写代码就会更加灵活， 后期慢慢就能理解了。

## 5.const修饰指针

### 5.1const修饰常量

```c

```

![](H:\Cplusplus\Cplusplus\ArticleWirting\指针1\Images\const1.png)

这样子修改a的值是完全没有问题的，那么我们现在加上const

```c

```

![](H:\Cplusplus\Cplusplus\ArticleWirting\指针1\Images\const2.png)

现在可以看见在const修饰之后，a的值不可再被修改，那么a现在是常量吗？我们可以来验证一下

```C
const int a = 10;
int arr[a] = { };
printf("%d\n",a);
```

![](H:\Cplusplus\Cplusplus\ArticleWirting\指针1\Images\const3.png)

因为在数组中我们，必须为常量，我们将const修饰的a放进去，可以看见报错信息是表达式必须含有常量值，那么由此可见即便变量a被const修饰，a本质上也还是变。不过，这也和编译语言有关，在c++中a被const修饰之后就变成了常量



那么如果我想把const修饰的变量值进行修改一个怎么做呢？

```c

![](H:\Cplusplus\Cplusplus\ArticleWirting\指针1\Images\const4.png)

这就相当于我们把门关了不让别人拿东西，但是他们的手又从窗户伸进来了。

但是，加const的本意就是不让修改a的值，但是还是被修改了，那我们应该怎么办呢？
