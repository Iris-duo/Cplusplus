### 3.3布置雷

我们以10颗雷为例，使用随机函数在棋盘不同位置生成雷，那么如何在不同位置生成雷呢

`rand()` 其实是“伪随机”——你不给它种子，它每次开机产生的“随机”序列**一模一样**，你的雷每局都在同样的位置。`srand` 是“播种”，`time(NULL)` 是当前时间的秒数，每秒都不一样，所以每局雷的位置都不同。这句**整个程序只写一次**，放在 main 最前面。

```c
//布置雷
	void SetMine(char mine[ROWS][COLS], int row, int col, int count)
	{
		while (count > 0)
		{
			int x = rand() % row + 1;   // 随机行：1 ~ row
			int y = rand() % col + 1;   // 随机列：1 ~ col

			if (mine[x][y] == '0')      // 这个位置还没雷
			{
				mine[x][y] = '1';       // 放一颗
				count--;                // 待放的雷少一颗
			}
			// 如果这个位置已经是雷了：什么都不做，while 再转一圈重新随机
		}
	}
```

那么根据我们刚才的分析才想要布置位置不重复我们还需要再主函数中添加

```
	srand((unsigned int)time(NULL)); // 设置随机数种子
```

3.4 数雷个数

格子(x,y)周围有八个格子，每个格子里是字符’1‘(雷)或’0‘(安全)。怎么数出有几颗雷呢？

**核心知识：字符在电脑里就是数字。** 每个字符对应一个 ASCII 编码：

字符 '0' 在电脑里存的是 48
字符 '1' 在电脑里存的是 49
字符 '2' 在电脑里存的是 50

所以字符可以直接当数字加减：

- `'1' - '0'` = 49 − 48 = **1**（字符相减得到数字差）
- `3 + '0'` = 3 + 48 = 51 = **'3'**（数字加 '0' 变回字符）

**现在看那行 return**：把周围 8 个字符全加起来。假设周围有 3 颗雷，那就是 3 个 `'1'` 加 5 个 `'0'`，等于 8 个 `'0'` 再加 3。所以**减去 `'0' \* 8`**，剩下的就是纯数字 3。✨

**`static` 是什么意思？** “这个函数只在本文件内部使用，别的文件不许碰”。不对外开放的函数加 static，是好习惯，防止别的文件里有同名函数打架。

> 看到没有，围墙（第 3 步的 +2）在这里立功了：就算 (x,y) 在棋盘最边缘，`x-1`、`y+1` 也落在围墙里，是合法的 `'0'`，**不用写任何“如果在角落就特殊处理”的代码**。

```
static int GetMineCount(char mine[ROWS][COLS], int x, int y)
{
	return mine[x-1][y-1] + mine[x-1][y] + mine[x-1][y+1]
	     + mine[x][y-1]   +               mine[x][y+1]
	     + mine[x+1][y-1] + mine[x+1][y] + mine[x+1][y+1]
	     - '0' * 8;
}
```

### 3.5 排雷

```
void FindMine(char mine[ROWS][COLS], char show[ROWS][COLS], int row, int col, int mine_count)
{
	int x = 0;
	int y = 0;
	int win = 0;                          // 已经安全翻开的格子数
	int target = row * col - mine_count;  // 目标：翻开所有非雷格

	while (win < target)
	{
		printf("请输入要排查的坐标:> ");
		scanf("%d %d", &x, &y);

		if (x >= 1 && x <= row && y >= 1 && y <= col)   // 坐标合法吗
		{
			if (show[x][y] == '*')                      // 这格还没翻过
			{
				if (mine[x][y] == '1')                  // 踩雷了！
				{
					printf("很遗憾，你踩到雷了\n");
					DisplayBoard(mine, row, col);
					break;                              // 跳出循环，游戏结束
				}
				else                                    // 安全
				{
					int count = GetMineCount(mine, x, y);
					show[x][y] = count + '0';           // 数字变字符，写回show
					DisplayBoard(show, row, col);
					win++;
				}
			}
			else
			{
				printf("该坐标已经排查过，请重新输入\n");
			}
		}
		else
		{
			printf("坐标无效，请重新输入\n");
		}
	}

	if (win == target)
		printf("恭喜你，排查成功\n");
}
```

**逻辑骨架**就是三层俄罗斯套娃，每一层都是一个“安检口”：

plain



```plain
while（还没赢）
   └─ if（坐标在范围内吗？）
        └─ if（这格还没翻过吗？）
             └─ if（是雷吗？）→ 是：炸；否：翻开
```

**`win < target` 的数学**：9×9 共 81 格，10 颗雷，所以非雷格有 71 个。玩家每安全翻开一格 `win++`，翻开全部 71 格时循环结束——**赢了**。

**`show[x][y] = count + '0'`**：又是 ASCII 魔术——假设 count 是 3，`3 + '0'` 等于字符 `'3'`，存进 show 棋盘，下次打印出来玩家就看到数字 3。

**`break`**：立刻跳出当前这层循环。踩雷时用。

**`&&`**：逻辑“并且”，两个条件都成立才算成立。

### 3.6递归展开(灵魂功能)

真正的扫雷：颠倒空白格，会自动展开一大片

先用人话讲清楚思路

> 我翻开一个格子 → 数它周围的雷：
>
> - 周围有雷（数字 1~8）→ 就显示这个数字，**结束**；
> - 周围 0 雷 → 显示空白，然后**对它周围 8 个格子分别重复上面这整个过程**。

“对周围 8 格重复同样的事”——**这就是递归**：一个函数在执行过程中调用它自己。
